How to read this

Five metrics, everywhere. Registrations, cost per registration, link clicks, cost per link click, and total spent. Every ranking on this page uses them and nothing else, so a video and a still are judged on the same terms.

One registration number, everywhere. Every registration figure on this page, from the headline down to a single creative, is the Hyros count under last-click attribution. Meta's own Lead pixel is not used for any ranking: it sees only the registrations it can match itself, and it undercounts this funnel by roughly three to one. Using both would put two different answers on one page.

Scope. Every campaign in Meta ad account 37394393 whose name contains "webinar", matched by name rather than by a fixed ID list, so next week's campaign is picked up without editing anything.

Link clicks are the clicks that actually left for the landing page (inline_link_clicks). All-clicks runs about 2.4x higher on this account and would flatter both the count and the cost.

Ranking. Registrations first, then cost per registration, then spend. Volume outranks efficiency on purpose: a single registration on a few dollars produces a spectacular cost and proves nothing. Rates are recomputed from summed components, never averaged across ads.

Source. Meta Graph API v21.0 and the Hyros attribution API, both read-only, both called live from this browser at the moment you press Refresh. Meta figures are on the ad account's own clock, America/Los_Angeles. Creative thumbnails are pulled fresh each time because Meta's image links are signed and expire. Nothing on this page is estimated, inferred, or cached from an earlier build.
